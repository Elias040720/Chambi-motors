# CHAMBI MOTORS V1

Brief: solicitud completa adjunta por el usuario en esta conversación. Un taller, una cuenta administradora, app nativa Android/iOS y portal cliente por enlace privado, sin pagos ni publicación autorizada.

| Hito | Aceptación |
|---|---|
| H0 Base | Rama aislada, workspaces, distribución demo identificada, configuración/documentación |
| H1 Dominio/persistencia | PostgreSQL, migración con RLS, contratos validados, invariantes de OT y autorización |
| H2 Corte vertical | Admin registra cliente/vehículo/OT/evidencia/enlace; el cliente solo ve la OT autorizada |
| H3 Operación | Tareas, estados, cotizaciones versionadas, decisiones y recepción de piezas |
| H4 QA/entrega | QA y retrabajos auditables, entrega e historial |
| H5 Resiliencia | Caché/borradores, medios privados, CI y UX de red/accesibilidad |
| H6 Verificación | Setup limpio, tipos, lint, build, pruebas relevantes; limitaciones reportadas |

No fusionar, subir, desplegar ni publicar apps. Marcar cada criterio con evidencia; compilación sola no demuestra comportamiento.
