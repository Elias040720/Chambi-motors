## Estándares y guías primarias de UI

- [W3C WCAG 2.2](https://www.w3.org/TR/WCAG/): criterios de contraste, foco y presentación. Los tests locales solo verifican algunos tokens CSS del fixture, no conformidad WCAG.
- [WAI: labels](https://www.w3.org/WAI/tutorials/forms/labels/) y [feedback de formularios](https://www.w3.org/WAI/tutorials/forms/notifications/): relación label/control y feedback comprensible de éxito/error.
- [W3C Media Queries Level 5](https://www.w3.org/TR/mediaqueries-5/): `prefers-reduced-motion` cuando haya motion no esencial.
- [web.dev Core Web Vitals](https://web.dev/articles/vitals): medir rendimiento en páginas/runtime reales. Ninguna métrica web vitals fue tomada en esta sesión.

La V4.2 reescribe los procedimientos de `design-director`, `ui-engineer`, `ux-reviewer`, `motion-reviewer`, `tech-lead` y QA según estos conceptos. Esto no implica adopción literal o componente integrado, ni evidencia todavía una mejora sobre V4.1. **No se declara superioridad de calidad/token efficiency sin el A/B real descrito en `tests/fixtures/eval/README.md`.** La licencia de este paquete nuevo no está decidida por el dueño; debe resolverse antes de redistribución pública.
