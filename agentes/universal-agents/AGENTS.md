# Mantenimiento del paquete universal

- Fuente única: `universal-agents/`; los paquetes de `../dist/` se generan.
- Mantén instrucciones breves y carga skills/referencias pertinentes por demanda.
- Respeta el stack, permisos, convenciones y cambios locales del proyecto consumidor.
- No actives hooks, MCP ni herramientas de terceros por un archivo del paquete.
- Distingue claims de evidencia observada y reporta los checks omitidos.
- No ejecutes scripts V2 archivados.
