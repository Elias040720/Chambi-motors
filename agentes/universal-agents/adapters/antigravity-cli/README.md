# Antigravity CLI

Proyecto: `.agents/skills`, `.agents/core`, `.agents/agents/*.md`, `.agents/rules/*.md`, `AGENTS.md`. Global: skills/core bajo `~/.gemini/antigravity-cli/`; agentes/reglas e instrucción bajo `~/.gemini/config/`. Las raíces globales separan CLI de la configuración compartida del IDE. Confirmar el modo CLI y descubrimiento de skills en la versión instalada antes de usar.
