# OpenCode

Proyecto: `.opencode/skills`, `.opencode/agents`, `.opencode/core`, `AGENTS.md`. Global: `~/.config/opencode/skills`, `agents`, `core`, `AGENTS.md`. No dupliques skills en `.agents/` porque OpenCode puede descubrir esa ruta de compatibilidad y producir nombres repetidos.
